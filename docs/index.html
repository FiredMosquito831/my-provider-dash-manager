My Provider Dash Manager — one desktop app for every account you own

Keep several Google, Microsoft, AWS, Vercel, Netlify, Supabase, Cloudflare, GitHub, npm, Stripe, Gmail and Outlook accounts signed in at the same time — 37 services built in, any site by URL — each in a fully isolated browser session. Switch between them like browser tabs, but built around accounts instead of pages.

npx my-provider-dash-manager

Why it exists

  • Every account stays signed in, in its own storage partition — no signing out to reach another.
  • One window: providers on the left, open accounts as tabs on top.
  • The open-tab set is remembered and restored on the next launch.
  • Built-in ad-blocking and Dark Reader-powered dark mode — no extensions required.
  • Logins encrypted with Windows DPAPI and bound to account and origin.
  • Import passwords from Chrome, Edge, Brave, Vivaldi, Opera or CSV — and choose which login autofills per account.
  • Silent in-place updates, downloaded in the background.
